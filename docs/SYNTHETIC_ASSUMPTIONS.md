# Synthetic Data Assumptions (CampaignIQ)
- All data generated by `data/generate_campaign_data.py`, seed 42, 30,000 users. No real PII or upay data.
- Randomized experiment: each user is assigned uniformly to 4 arms (control, 3 offers). Enables unbiased policy evaluation (IPW).
- Baseline conversion: logistic in transaction count, recency, tenure.
- Planted effects (the model must rediscover them; this is a limitation, see README):
  - Offer 1 (utility cashback): +25pp for lapsing-but-formerly-active users, +3pp otherwise.
  - Offer 2 (data bundle): +20pp for age 18-25 with low avg amount, +2pp otherwise.
  - Offer 3 (cash-out fee waiver): +22pp when cash-out ratio > 0.6, +1pp otherwise.
  - Fatigue: -4pp per offer in the last 30 days, extra -6pp at 4+ offers (can make users worse off).
  - Gaussian noise (sd 0.03) on each individual effect.
- Economics (assumptions): value of one conversion = 100 BDT; offer costs 30/15/20 BDT paid only on redemption.
- Region and age band are NOT model features; they are used only for fairness checks. Rural users have lower activity and higher cash-out ratio (proxy effect is intentional so the fairness check is meaningful).
- 70/30 train/test split, stratified by arm; the test set is never used for training.
